## How every teardown is built

Each teardown follows the same 65-part research brief, so they can be compared side by side. The brief is in [teardown-brief.md](teardown-brief.md).

- **Every important claim is labelled** FACT (a source says it directly), INFERENCE (my reasoned conclusion) or HYPOTHESIS (plausible, but not confirmable from public information).
- **Nothing is invented.** Where a number isn't public, such as revenue, churn or customer counts, the teardown says so.
- **Public sources only**, listed at the end of each teardown in a source register rated by reliability.
- **AI-assisted, human-reviewed.** I use Claude to research and draft against the brief, then review, correct and edit the result.
